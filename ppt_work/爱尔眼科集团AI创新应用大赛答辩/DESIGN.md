# DESIGN.md — 爱尔眼科集团AI创新应用大赛答辩

## 视觉基准（来自《【PPT模版】2026大视光年会PPT终版.pptx》）

模板解构结果：
- 画布 33.87 × 19.05 cm（16:9），本项目统一 1280 × 720 px
- 模板主色：`2033B8`（爱尔深蓝）、`0367CE`（亮蓝）、`48D1FF` / `2BC7FF`（青）、`60BEFC`（浅蓝）、`02046B`（暗夜蓝）、`ADE8FF`（淡青）
- 模板字体：中文黑体 / 微软雅黑，西文 Arial
- 模板元素：深蓝城市天际线底图、2026 线框数字 + EYE 线条标识、白色爱尔眼科 LOGO、蓝色斜切色带
- 模板母版：封面 / 目录 / 章节页（PART.01）/ 内容页 / 结束页 五段式

## 色彩池（≤4 hex + 中性）
| 角色 | Hex | 用途 |
| :-- | :-- | :-- |
| 主色 | `#0B2A6B` | 深底、标题栏、深色块（取自模板 02046B/2033B8 深化） |
| 辅色 | `#1B5FD9` | 卡片头、图表主系列、渐变起点（取自模板 0367CE/2033B8） |
| 强调色 | `#35C8F0` | 巨型数字、高亮、进度条、焦点标注（取自模板 48D1FF/2BC7FF） |
| 警示/落地 | `#FF8A3D` | 仅用于"痛点/待改进/风险"焦点，占比 ≤ 6% |
| 中性文字 | `#1A2440` / `#5A6B8C` / `#FFFFFF` / `#F2F6FD` | 正文、辅助、浅底 |

**衍生渐变**：`linear-gradient(135deg, #1B5FD9 0%, #35C8F0 100%)`（卡片头、进度条）
`linear-gradient(180deg, rgba(11,42,107,0.96) 0%, rgba(27,95,217,0.88) 100%)`（深底页文字保护层）
**半透明策略**：底图上叠 `rgba(11,42,107,0.55~0.78)` 蒙版；深底卡片用 `rgba(255,255,255,0.06)`；浅底页用 `rgba(27,95,217,0.06)`

**色彩面积分配（逐页）**
- Hero 页（02 / 05 / 10 / 11 / 13）：主色 55% + 辅色 20% + 强调色 15-20%
- Supporting 页（03 / 04 / 06 / 07 / 08 / 09 / 12 / 14 / 15）：主色 30% + 辅色 22% + 强调色 ≤ 5%
- 至少 3 页（02 / 11 / 13）配色比例显著区别于其他页
