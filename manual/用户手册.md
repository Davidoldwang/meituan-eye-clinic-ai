# 爱尔眼科美团电商运营AI助手 · 用户手册

> 版本：v1.2 | 更新日期：2026-06-15 | 适用对象：爱尔眼科视光科美团/大众点评运营人员

---

## 一、产品概述

**美团电商眼科运营AI助手** 是专为爱尔眼科视光科门诊定制的美团/大众点评全链路运营平台，覆盖从市场情报、内容创作、评价管理到数据分析、活动策划的完整运营闭环。

### 核心能力

| 能力域 | 覆盖模块 | 状态 |
|--------|---------|------|
| 市场情报 | 竞品分析、门诊采集 | ✅ |
| 内容创作 | 文案生成、套图生成、话术建议、主图诊断、文案优化 | ✅ |
| 评价管理 | 差评智能回复、评价数据统计 | ✅ |
| 多平台运营 | 美团运营诊断、私域运营、抖音策略、小红书策略、公众号运营 | ✅ |
| 数据分析 | 运营仪表盘、增长策略 | ✅ |

### 访问方式

- **本地访问**：`http://localhost:3000/meituan-agent.html`
- **启动方式**：双击 `启动服务.bat` 或在终端执行 `node server.js`

### 门诊切换

页面顶部左侧下拉菜单可切换门诊，支持手动新增门诊（名称/大众点评链接/美团截图）。

## 二、功能模块详解

### 1. 运营仪表盘（首页）

**功能概述**：展示当前门诊的核心运营数据概览，包括评分、评价数、标签分布、待办事项和快捷入口。

**关键数据**：
- 门诊评分 & 评价数
- 标签分布（服务好、环境好、干净整洁等）
- GMV趋势图（近30天）
- 待办事项提醒（差评未回复、项目待优化等）

**快捷入口**：竞品分析、文案生成、套图生成、话术建议 四个高频功能一键直达。

---

### 2. 竞品分析

**功能概述**：输入竞品门诊名称和城市，AI自动生成竞品分析报告，覆盖品牌定位、项目结构、价格策略、评价口碑、优劣势对比。

**操作步骤**：
1. 输入竞品门诊名称（如"何氏眼科"）
2. 选择城市（如"临沂"）
3. 点击「开始分析」
4. 查看五维度对比报告（定位/项目/价格/评价/优劣）

**适用场景**：新门诊上线前对标、定期竞品监测、PK赛对手分析

---

### 3. 文案生成

**功能概述**：基于产品矩阵（引流款/利润款/组合款），AI自动生成7屏美团内页完整文案，包含标题钩子、信任建立、痛点共鸣、流程说明、医生背书、价格锚点和行动号召。

**操作步骤**：
1. 选择产品矩阵 → 输入项目名称、价格、卖点
2. 配置模板类型（引流款/利润款/组合款）
3. 点击「生成文案」
4. 一键复制使用

**输出格式**：标题 + 副标题 + 7段完整正文，适配美团详情页排版

---

### 4. 套图生成

**功能概述**：选择设计风格和主题，AI生成完整套图方案（含主图布局、配色、文案、素材建议），支持AI生图预览。

**操作步骤**：
1. 选择风格（专业医疗风/温馨信任风/科技感/极简风）
2. 输入主图主题和关键词
3. 选择生成数量（1-4张）
4. 点击「AI生成主图」

**技术说明**：对接火山引擎Seedream模型，支持文生图和图生图两种模式。

---

### 5. 话术建议

**功能概述**：针对美团IM咨询/电话咨询/到店接待等不同场景，生成标准化话术脚本，一键复制使用。

**操作步骤**：
1. 选择场景（初次咨询/价格询问/疑虑解答/促单跟进）
2. 选择产品类型（OK镜/离焦镜/视光检查）
3. 点击「生成话术」
4. 查看场景化话术卡片并复制

---

### 6. 评价管理

**功能概述**：差评智能回复、好评引导策略、评价健康度诊断三位一体。

**操作步骤**：
1. **差评回复**：输入差评内容 → 选择回复风格（真诚道歉/专业解释/补偿安抚）→ AI生成回复 → 一键复制
2. **好评引导**：查看智能好评引导策略
3. **评价统计**：查看评分分布、差评率趋势、回复率统计

**注意事项**：所有AI回复均经合规检查，避免医疗广告违规用语。

---

### 7. 美团运营诊断

**功能概述**：全面诊断美团店铺运营状态，覆盖项目设置、定价、销量、评价四个维度，输出P0/P1/P2优先级优化建议。

**操作步骤**：
1. 选择诊断维度（全维度/单项）
2. 点击「开始诊断」
3. 查看诊断报告：评分概览 + 分维度详细分析 + 优化建议清单
4. 一键跳转「生成优化方案」

**适用场景**：月度运营复盘、新门诊上线前检查、问题门诊专项诊断

---

### 8. 私域运营

**功能概述**：企业微信SCRM、复查提醒、社群运营一站式方案生成。

**操作步骤**：
1. 选择运营方向（企微SCRM/复查提醒/社群运营）
2. 输入关键参数（患者量/门诊类型）
3. 点击「生成方案」
4. 获取完整执行方案 + 话术模板 + 排期建议

---

### 9. 抖音策略

**功能概述**：短视频脚本、直播方案、投放策略一站式生成。

**操作步骤**：
1. 选择内容类型（短视频/直播/信息流广告）
2. 填写核心信息（产品/目标人群/预算）
3. 点击「生成策略」
4. 获取完整执行方案：脚本框架 + 拍摄清单 + 投放建议 + 预算分配

---

### 10. 小红书策略

**功能概述**：种草笔记框架、达人合作策略、趋势话题运营。

**操作步骤**：
1. 选择内容类型（种草笔记/达人合作/趋势运营）
2. 填写核心信息
3. 点击「生成策略」
4. 获取方案：笔记框架 + 话题标签 + 发布时间建议 + KOL筛选标准

---

### 11. 公众号运营

**功能概述**：推文策划、菜单架构、内容日历。

**操作步骤**：
1. 选择运营维度（推文策划/菜单架构/内容日历）
2. 填写门诊信息和内容方向
3. 点击「生成方案」
4. 获取完整内容方案

### 12. 增长策略

**功能概述**：转化漏斗分析、渠道ROI测算、增长实验设计、月度运营计划。

**操作步骤**：
1. 选择分析维度
2. 填写关键指标
3. 点击「生成策略」
4. 查看：漏斗诊断 + 优化方向 + 实验设计 + 月度执行计划

---

### 13. 门诊采集分析（⭐核心功能）

**功能概述**：上传美团门诊截图或输入大众点评网址，AI自动采集门诊数据并分析项目设置、定价、销量、评价，输出综合优化建议。

**两种采集方式**：
- **截图上传**：截取美团门诊页面 → 拖拽或点击上传 → AI识别
- **URL输入**：粘贴大众点评门诊链接 → AI抓取分析

**分析维度**：
- 项目结构合理性（品类覆盖、引流款/利润款配比）
- 价格竞争力（与同城竞品对标）
- 销量健康度（热销/滞销项目识别）
- 评价质量（好评/差评关键词分析）

**输出内容**：门诊基础信息 + 项目清单 + 五维度分析 + P0/P1/P2优化建议

**适用场景**：新门诊数据采集、竞品门诊分析、薄弱门诊诊断、门诊间横向对比

---

### 14. 主图诊断（M3 Phase 1 新功能）

**功能概述**：上传美团团购项目主图，AI从5个维度进行专业诊断并给出优化建议。

**诊断维度**：

| 维度 | 说明 | 权重 |
|------|------|------|
| 清晰度 | 图片分辨率、背景整洁度 | 20% |
| 品牌感 | Logo、品牌色、门诊标识 | 25% |
| 信息度 | 价格标签、核心卖点突出度 | 20% |
| 情感力 | 医生/儿童场景、信任感 | 15% |
| 品类匹配 | 图片风格与项目品类匹配度 | 20% |

**操作步骤**：
1. 拖拽或点击上传主图（支持JPG/PNG/WebP）
2. 填写项目名称、选择品类
3. 点击「开始诊断」
4. 查看综合评分 + 五维度进度条 + 问题发现 + 优化建议 + 快速见效标签
5. 可一键跳转「生成优化文案」或「重新诊断」

**输出结果解读**：
- **80-100分**：主图优秀，建议定期微调
- **60-79分**：有提升空间，关注黄色标记维度
- **<60分**：急需优化，优先处理红色P0级问题

---

### 15. 详情页文案优化（M3 Phase 2 新功能）

**功能概述**：粘贴现有美团项目详情页文案，AI从5个维度诊断并自动生成优化版本。

**诊断维度**：

| 维度 | 说明 |
|------|------|
| 吸引钩子 | 是否有痛点共鸣、数据锚定 |
| 信任建立 | 是否有资质背书、数据支撑 |
| 信息清晰度 | 是否有分步骤流程说明 |
| 行动紧迫感 | 是否有CTA按钮、限时限量元素 |
| 合规性 | 是否违反广告法、美团规则 |

**合规检查规则**：
- 绝对化用语检测（"最好""第一""唯一"等）
- 患者名义证明检测
- 疗效承诺检测（"保证""确保"等）
- 315敏感词检测
- 价格标示合规检测
- 机构比较用语检测

**操作步骤**：
1. 粘贴原始详情页文案到文本框
2. 填写项目名称、团购价格、目标人群（选填）
3. 点击「分析并优化」
4. 查看优化版文案 + 五维度评分 + 合规检查结果 + 关键改进清单
5. 点击「复制优化文案」或「重新分析」

**优化策略**：自动生成四段式结构（痛点钩子→信任背书→流程说明→价格CTA+温馨提示）

## 三、常见问题（FAQ）

### Q1：页面打不开怎么办？

A：确保已启动后端服务。双击 `启动服务.bat` 或在终端执行 `node server.js`，看到"美团眼科运营AI助手 后端服务"提示后访问 http://localhost:3000/meituan-agent.html

### Q2：端口3000被占用怎么办？

A：编辑 `server.js` 第13行，将 `const PORT = process.env.PORT || 3000;` 中的 `3000` 改为其他端口（如 `3001`）。

### Q3：某些功能返回"AI服务异常"？

A：部分功能（如竞品分析、文案生成）依赖后端AI逻辑，如果后端服务未启动或异常，会自动降级为本地模拟数据。请确认 `node server.js` 正常运行，且终端无报错。

### Q4：如何新增门诊？

A：点击顶部门诊名称右侧下拉箭头 → 选择「+ 新增门诊」→ 支持三种方式：手动输入名称、粘贴大众点评链接、上传美团截图。

### Q5：AI生成的内容质量不满意？

A：所有生成内容均可作为初稿参考，建议根据实际情况人工调整。主图诊断和文案优化模块提供五维度评分和具体改进建议，可据此定向优化。

### Q6：支持哪些浏览器？

A：推荐使用 Chrome、Edge、Firefox 最新版本。IE 不支持。

### Q7：能否在手机端使用？

A：页面已做移动端自适应适配，支持768px以下屏幕。但部分功能（如门诊截图上传）在PC端体验更佳。

### Q8：数据存储在哪里？

A：自定义门诊数据存储在浏览器 localStorage 中。后端服务不持久化数据，重启后所有分析结果重新计算。
