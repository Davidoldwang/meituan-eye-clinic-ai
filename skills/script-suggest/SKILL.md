# 话术建议技能

## 使用场景
- 新员工培训需要标准话术
- 不同场景需要差异化的沟通话术
- 需要提升转化率的升级引导话术

## 场景分类（5类）
1. **预约确认**：短信格式 + 企微格式，含检查注意事项
2. **到店接待**：前台话术 + 候诊引导话术
3. **检查结果**：正常/需观察/需干预 三种结果的不同话术
4. **升级引导**：引流款→利润款转化 + 单次→套餐转化
5. **离店跟进**：48小时跟进 + 7天复查提醒

## 话术要求
- 包含真实门店信息：临沂爱尔眼科光门诊(金水河畔店)
- 引用医生信息：杜秀臻医生，从业10年
- 地址：临沂市兰山区金水河畔
- 电话：0539区号
- 语气亲切专业，避免过度推销
- 加入随机表述变化，模拟人工风格

## 输出格式
- 每个场景返回2-3条完整话术
- 每条包含：名称、描述、完整话术文本、图标颜色
- 话术可直接复制使用

## 注意事项
- 话术需符合医疗广告法规，不夸大疗效
- 升级引导需自然过渡，不强行推销
- 跟进话术需体现关怀，不催促
