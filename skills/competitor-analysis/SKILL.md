# 竞品分析技能

## 使用场景
- 用户上传竞品美团截图或文字信息
- 需要生成竞品对比分析报告
- 需要了解我方与竞品的差距和优势

## 分析维度
1. 项目名称对比
2. 价格对比（含差距百分比）
3. 评分对比
4. 评价数对比
5. 主图风格对比
6. 有效期对比

## 输出格式
- 6维对比表（红/黄/绿三级标注）
  - 绿色(good)：我方领先或持平
  - 黄色(warn)：存在差距需优化
  - 红色(bad)：差距较大需紧急处理
- 3条优化建议（P1/P2优先级）
- 建议内容需结合眼科门诊专业场景

## 数据来源
- 用户输入：竞品文本信息（粘贴美团页面文字）
- 自动解析：名称、价格、评分、评价数、有效期
- 默认竞品：临沂华厦眼科

## 注意事项
- 对比数据需客观，不夸大我方优势
- 优化建议需可执行，有具体数据支撑
- 价格差距百分比需精确计算
- 评分差距0.1以上视为有实际意义
