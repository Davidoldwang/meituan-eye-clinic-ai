# 套图生成技能

## 使用场景
- 新项目上线需要制作美团图片素材
- 现有项目图片需要更新设计风格
- A/B测试需要不同风格的图片方案

## 风格方案
1. **亲子温暖型(warm)**：蓝绿配色#06b6d4/#10b981，温馨家庭感
2. **专业信任型(pro)**：深蓝白配色#1a3a5c/#3b82f6，权威医疗感
3. **优惠促销型(promo)**：红黄配色#ef4444/#f59e0b，活力促销感
4. **高端医疗型(premium)**：深灰金色配色#1f2937/#d97706，高端质感

## 生成图片（4张）
1. **内页图·第1屏**：750×1400px — 利益钩子页
2. **内页图·第2屏**：750×1400px — 痛点场景页
3. **主图A/B测试**：800×800px — 列表主图
4. **活动Banner**：1200×400px — 活动横幅

## 设计规范
- 渐变背景：根据风格使用双色渐变
- 标题文字：白色，36px加粗
- 副标题：白色85%透明度，22px
- 装饰元素：半透明圆形、线条、价格标签
- 品牌水印：底部居中，50%透明度

## 输出格式
- 每张图返回：画布尺寸、背景色、标题文字、副标题文字、装饰元素位置
- 前端使用Canvas API渲染实际图片
- 支持下载为PNG格式

## 注意事项
- 文字需适配750px宽度，超出自动换行
- 颜色对比度需保证文字可读性
- 主图需突出价格和产品名
