# 公众号运营技能

## 使用场景
- 眼科门诊公众号内容策划和推文撰写
- 菜单架构设计和自动化回复
- 粉丝增长和互动策略
- 图文排版和视觉规范
- 公众号→私域转化路径

## 核心能力

### 1. 内容策划
- **60/30/10法则**：60%护眼干货 + 30%互动内容 + 10%促销内容
- **内容栏目**：
  - 「护眼小课堂」：科普干货，每周1篇
  - 「名医在线」：医生专访/答疑，每两周1篇
  - 「患者故事」：真实案例分享，每月1篇
  - 「优惠活动」：促销信息，每月1-2篇
- **发布频率**：2-3篇/周，固定时间推送(周二/四/六 19:30)

### 2. 爆款推文结构
| 类型 | 标题公式 | 开头套路 | 结尾CTA |
|------|---------|---------|--------|
| 科普类 | "[数字]+个护眼习惯，第[X]个90%人不知道" | 痛点提问 | "转发给家人" |
| 故事类 | "8岁近视[X]度，1年后竟然……" | 悬念设置 | "预约检查" |
| 活动类 | "限时[X]元｜[节日]护眼礼包开抢" | 价值锚定 | "点击抢购" |
| 评测类 | "OK镜VS离焦镜，到底怎么选？" | 对比冲突 | "咨询专家" |

### 3. 菜单架构
```yaml
底部菜单:
  - 护眼服务:
      - 在线预约(跳转小程序)
      - 专家团队(医生介绍页)
      - 门店导航(地图+地址)
  - 眼健康:
      - 护眼知识(文章合集)
      - 近视防控(专题页)
      - 自测工具(视力自测H5)
  - 会员中心:
      - 我的积分(会员页)
      - 复查提醒(订阅消息)
      - 在线咨询(企微客服)
```

### 4. 粉丝运营
- **增长策略**：到店扫码关注→领优惠券/免费眼检券
- **打开率目标**：>15%(医疗行业平均8-12%)
- **互动设计**：文末提问/投票/有奖问答
- **关键词回复**：OK镜/近视/配镜/预约→自动回复对应内容

### 5. 转化路径
- 公众号推文→阅读原文→美团团购链接
- 公众号菜单→在线预约→企微客服→到店
- 公众号活动→扫码进群→社群运营→复购

## 输出格式
- 月度内容日历(含选题/类型/发布时间)
- 单篇推文稿件(含标题/正文/配图说明/CTA)
- 菜单架构方案(含一级/二级/跳转链接)
- 自动回复配置(含关键词/回复内容)
