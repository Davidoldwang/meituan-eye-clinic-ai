# 美团/大众点评运营技能

## 使用场景
- 美团店铺装修和团购项目上线/优化
- 推广通(直通车)投放策略和ROI优化
- 评价管理和差评回复策略
- 大促活动策划(双11、618、开学季等)
- 竞品对标和品类排名提升

## 核心能力

### 1. 店铺运营
- **店铺装修**：头图轮播、商家相册、环境视频、医生介绍
- **团购项目结构**：引流款(9.9体检) + 利润款(OK镜/离焦镜) + 套餐款(年度护眼)
- **项目标题优化**：[品牌]+[核心关键词]+[属性]+[卖点]+[场景]
- **详情页7屏文案**：利益钩子→痛点场景→服务流程→资质背书→真实评价→FAQ→预约CTA

### 2. 推广通投放
- **搜索推广**：关键词竞价(眼科、近视、配镜、OK镜等)
- **信息流推广**：人群定向(3-15岁家长、近视人群)
- **ROI管理**：目标ROAS 3:1起步，单次获客成本<80元
- **投放节奏**：工作日白天搜索推广，周末全天信息流+搜索

### 3. 评价管理体系
- **好评引导**：到店后3天内推送评价邀请，附赠小礼品
- **差评回复**：24小时内回复，先道歉→说明→解决方案→联系方式
- **评价分析**：按维度(服务/效果/价格/环境/等待)归类，月度生成报告
- **评分维护**：目标4.8+，低于4.6需紧急干预

### 4. 活动策划
- **节点日历**：3月开学季/6月爱眼日/9月开学季/双11/寒假
- **活动机制**：限时折扣、满减、第二件半价、老带新
- **预算分配**：推广费用30% + 折扣让利40% + 物料制作20% + 奖品10%
- **数据复盘**：GMV、ROI、新客占比、复购率

### 5. 数据分析
- **核心指标**：曝光量→点击率→转化率→到店率→成交率
- **流量来源**：搜索流量/推荐流量/活动流量/品牌流量
- **竞品对标**：周度对比TOP5竞品的评分/价格/销量/评价数

### 合规红线
- 禁止使用"治愈近视""恢复视力"等绝对化用语
- 医疗广告需标注医疗广告审查证明号
- 不承诺具体度数降低效果
- 价格标注需清晰透明，不含隐性消费

- 推广投放方案(含关键词/出价/预算/时段)
- 活动策划方案(含时间表/预算/预期GMV)
