# 患者私域运营技能

## 使用场景
- 企微患者管理和分层运营
- 复查提醒和复购引导
- 患者社群运营(微信群/企微群)
- 会员积分体系设计
- 患者生命周期管理

## 核心能力

### 1. 企微SCRM体系
- **渠道活码**：美团订单→包装卡→企微好友自动分配
- **自动标签**：来源渠道/消费层级/产品类型/生命周期/眼疾类型
- **欢迎语**：自动推送+首购优惠券+产品使用指南
- **客户继承**：员工离职自动转移患者，防止资产流失

### 2. 患者分层运营
| 层级 | 条件 | 运营策略 | 触达频率 |
|------|------|---------|---------|
| 新患者 | 首次到店0-7天 | 激活体验+使用指导 | 1次/天 |
| 活跃患者 | 30天内有互动 | 内容种草+复购提醒 | 2次/周 |
| VIP患者 | 累计消费>5000 | 专属顾问+优先预约 | 1次/周 |
| 沉默患者 | 90天无互动 | 激活优惠+关怀回访 | 1次/月 |
| 流失预警 | 互动频次持续下降 | 1v1诊断+专属方案 | 即时触发 |

### 3. 复查提醒自动化
- **OK镜**：配镜后1周→1月→3月→6月→12月
- **离焦镜**：配镜后1月→3月→6月→12月
- **功能镜**：配镜后3月→6月→12月
- **提醒模板**：温馨关怀型/专业提醒型/优惠激励型
- **推送渠道**：企微消息→短信→电话(递进)

### 4. 社群运营SOP
- **早8:30**：护眼小知识(图文)
- **中12:00**：互动话题/投票
- **晚19:30**：案例分享/专家答疑预告
- **周活动**：会员日优惠/限时秒杀
- **内容比例**：70%科普干货 + 20%互动活动 + 10%产品推广

### 5. 复购引导策略
- **升级引导**：功能镜→离焦镜 / 单次检查→年度套餐
- **家庭拓展**：孩子配镜→家长眼健康检查→全家护眼方案
- **转介绍激励**：老带新各得200元券 / 推荐3人免费年检

## 眼科门诊专项

### 患者生命周期管理
```yaml
新患者激活(0-7天):
  - 0min: 自动欢迎语+产品使用指南
  - 24h: 首次体验关怀
  - 3天: 适应性回访(OK镜佩戴/镜片适应)
  - 7天: 邀请评价+社群邀请

成长期运营(7-90天):
  - 内容种草: 护眼知识/案例分享
  - 复查提醒: 按产品周期推送
  - 交叉推荐: 同类产品升级/家庭扩展

成熟期维护(90天+):
  - VIP专属: 优先预约/生日关怀
  - 年度复查: 续配提醒/换镜优惠
  - 转介绍: 老带新激励计划

流失预警与挽回:
  - 信号: 30天未打开消息/复查超期未到/社群退群
  - 动作: 1v1电话关怀→专属优惠→到店邀约
```

### 合规要求
- 医疗行业企微内容需合规审核
- 患者隐私保护，不泄露检查数据
- 推广内容不夸大疗效
- 获得患者知情同意后添加企微

## 输出格式
- 企微SCRM配置方案(含标签体系/自动化流程)
- 复查提醒模板(含时间节点/话术)
- 社群运营SOP(含内容日历/活动方案)
- 患者分层运营策略(含分层标准/触达方案)
